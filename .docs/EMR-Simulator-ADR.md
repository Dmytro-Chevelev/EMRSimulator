# ADR - Architecture Decisions

## ADR-001: .NET 8
Decision: Use .NET 8 for backend.
Reason: Alignment with enterprise ecosystem, performance, LTS support.

## ADR-002: SQLite for POC
Decision: Use SQLite.
Reason: Zero infrastructure, portable, simple local development.

## ADR-003: Provider Pattern
Decision: One simulator implementation per EMR.
Reason: Isolates provider-specific behavior.

## ADR-004: Scenario Engine
Decision: Scenario-driven responses.
Reason: Deterministic testing and debugging.

## ADR-005: Angular Admin UI
Decision: Angular preferred.
Reason: Rich SPA experience and future extensibility.

## ADR-006: Synthetic Data Only
Decision: No PHI.
Reason: Compliance and safe local development.
